Angle and cosine similarity

The dot product with the lengths divided out: a number from −1 to 1 that depends only on direction.

01 Meaning

The Dot product mixes two things: how well two arrows line up, and how long they are. To keep only the alignment, divide the lengths out. The result, cosine similarity, is the cosine of the angle between the arrows. It is 1 when they point the same way, 0 at right angles and −1 when they point in opposite directions. Make one arrow ten times longer and nothing changes.

For vectors of length 1 the lengths are already 1, so cosine similarity is just the dot product. And there is one case with no answer: the zero vector has no direction, so it has no angle with anything, and cosine similarity is undefined for it. Code must check for that case instead of dividing by zero.

cos θ = (a·b) / (‖a‖‖b‖)

02 Picture

The blue arrow a stays put. Turn b with the direction slider and stretch it with the length slider. The burgundy arc is the angle. Notice that the dot product changes with the length but the cosine does not. Slide the length down to 0 to see what happens at the zero vector.

Cosine ignores length

03 Real life

  • Two compass bearings: the angle between “north-east” and “east” is the same whether you look at a street or a continent.
  • Two recipes written as amounts of the same ingredients: a double batch has the same proportions, so its cosine with the original is 1.
  • Two documents as word counts: a short note and a long essay on the same topics have a cosine near 1, although the essay has far larger counts.
  • Two people’s ratings of the same films, once each person’s average is removed: similar tastes point the same way.

Recognition rule. If you want “same direction, whatever the size”, divide the dot product by both lengths.

Spot it. A short tweet and a long article mention the same topics in the same proportions. Describe each as a list of word counts. Which measure says they are alike?

04 Worked example

Predict, then reveal

Is (6, 8) a stretched copy of (3, 4)? What is the angle between an arrow and its stretched copy?

05 Why and when

When the size of a vector is incidental (a long document, a loud recording, a big population), cosine similarity compares the pattern without the size. It always lies in [−1, 1], so it is easy to read.

When it does not fit. If size carries meaning, cosine similarity throws it away; the raw dot product keeps it. And it is undefined for the zero vector, so any program must handle that case. Computing the angle needs an arccosine; rounding can push the quotient just past 1, so code clamps it into [−1, 1] first.

06 How to arrive at it

✓ Derived

  1. The requirement. A number that depends on direction only: if either arrow is stretched by a positive factor, the number must not change.
  2. The problem. The dot product a·b is multiplied by c if you stretch a by c.
  3. The fix. Divide by something that is also multiplied by c: the length ‖a‖. Do the same for b. The quotient (a·b) / (‖a‖‖b‖) is unchanged by any positive stretching.
  4. The range. Since a·b = ‖a‖‖b‖ cos θ, the quotient is cos θ, so it lies between −1 and 1.

Before you continue, predict: what is the cosine similarity of an arrow with itself?

I have made my prediction: show the reasoning

1. The angle between an arrow and itself is 0°, and cos 0° = 1. Equivalently, a·a = ‖a‖², and dividing by ‖a‖‖a‖ leaves 1.

07 In an LLM

  • Embedding similarity search. Systems that search a collection of embedding vectors for the ones most like a query commonly rank them by cosine similarity or by a dot product; the choice varies between systems. This is common practice in vector-search tools, not a statement about any particular model or company.
  • Why the two often agree. If every vector has first been scaled to length 1, cosine similarity and the dot product are the same number, so ranking by one ranks by the other.

Simplified. This is a general description of how such search is commonly done. It says nothing about how any particular embedding model is trained or normalised.

Explain it back

It divides the dot product by both lengths, so stretching either arrow by a positive factor cancels out. The zero vector has length 0, so the division would be 0 divided by 0; it also has no direction, so there is no angle to measure.

Teach it

60-second explanation

“Cosine similarity is the dot product with the lengths divided out. It is 1 for the same direction, 0 at right angles, −1 for opposite. It ignores how long the arrows are, so a short note and a long essay on the same topic can match. It is undefined for the zero vector, because that has no direction.”

Everyday analogy

Two people pointing at the same star: how far away each one’s finger reaches does not matter, only where it points. Where it breaks down: fingers have a length that sometimes matters; cosine throws it away.

Whiteboard sequence

  1. Draw a and b from one point with an angle between them.
  2. Write a·b = ‖a‖‖b‖ cos θ.
  3. Divide both sides by ‖a‖‖b‖.
  4. Stretch b to twice the length and show the cosine does not move.
  5. Shrink b to a point and write “0/0: undefined”.

Questions learners ask

Why between −1 and 1? Because it is a cosine of an angle.

Is it a distance? No. It is a similarity: 1 means most alike, whereas a distance of 0 means most alike.

What if the vectors are already length 1? Then cosine similarity is the dot product.

Common misconception

“Cosine similarity of 0 means the vectors are unrelated.” It means they are at right angles, which for word counts often means no shared words; it is not a general statement about meaning.
