Module 3

Matrix decompositions

What a matrix does to space, and how to break it into simpler pieces: the area it scales, the directions it only stretches, and the rotate-stretch-rotate that every matrix is. Six ideas, each from a picture first, then the symbols, then what it means for a language model.

About 73 min · 6 concepts

By the end of this module you’ll be able to…

  • Read the determinant of a 2×2 matrix as a signed area scale, and say what a zero or negative value means
  • Find the eigenvalues and eigenvectors of a 2×2 matrix and say when there are none, or too few
  • Write a matrix as PDP⁻¹, use it to compute powers, and say when it cannot be done
  • Describe any matrix as rotate, stretch, rotate with the SVD, and read its singular values as the axes of an ellipse
  • Build the best low-rank approximation of a matrix and count the numbers it stores
