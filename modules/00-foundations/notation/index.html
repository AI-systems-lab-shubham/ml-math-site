Reading mathematical notation

Symbols are shorthand: read them aloud and they become sentences.

01 Meaning

Notation is shorthand, like “tsp” for teaspoon. Each mark is a word or a hint about how to read the symbol next to it. A few turn up everywhere:

MarkRead aloudMeaning
x₃“x sub 3”a subscript picks the third entry
ŷ“y hat”a hat marks an estimate or prediction
x ∈ S“x is in S”element of a set
∀ i“for all i”for all: true for every one
𝐱“bold x”a vector: a list of numbers
ℝ“the reals”the real numbers

02 Picture

The list x has five entries (in print, a list like this is often set in bold). The small number below each is a subscript: a position label that says which entry. Move the slider to point at a different box.

x with a subscript picks one entry

03 Real life

  • Chess notation: “Nf3” packs a piece and a square into three characters.
  • Sheet music: dots on a staff stand for pitch and length.
  • Recipe shorthand: “2 tbsp”, “350°F”.

Recognition rule. A symbol you don't know: check what is attached to it (a subscript, a hat, bold type), read the whole line aloud, then look the symbol up.

Spot it. How do you read “x₂ ∈ ℝ”?

05 Why and when

Notation packs a long sentence into a line so you can see the structure at a glance. Without it, a formula about a thousand numbers would be a thousand words.

It only helps if you can read it, so when stuck, translate the line into words one mark at a time.

06 How to arrive at it

◆ Convention

Every mark here is a Convention. Books differ: some draw vectors with an arrow instead of bold, some number entries from 0. Check the notation page of whatever you are reading.

07 In an LLM

The link is conceptual: papers about language models are written in this notation, with data as xᵢ, predictions as ŷ and vectors in bold, so reading it is a prerequisite for reading them. Nothing about a model changes with the notation.

Teach it

Everyday analogy

Street numbers: “12” on a road picks one house out of many. Where it breaks down: house numbers are not always consecutive, subscripts usually are.

Common misconception

“A subscript means multiply.” It is a label for which item, nothing more.
