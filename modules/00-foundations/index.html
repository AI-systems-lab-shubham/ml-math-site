Variables and expressions

A letter can stand for a quantity, and an expression describes how quantities are combined.

01 Meaning

Think of a variable as a labelled box for a quantity that may change. An expression tells you what to do with the value in the box. For example, double a quantity and add one: 2x + 1. The symbol x is the value that can vary.

02 Picture

Change the value in the box

The rule stays the same.
When x is 3, 2x + 1 is 7.

03 Real life

A taxi fare may combine a fixed starting fee and a charge for distance; a recipe can scale ingredient amounts; a temperature reading can be converted between units. In each case, a letter can stand for the quantity that changes.

Recognition rule: if a written rule contains a placeholder whose value can change, look for a variable; the whole recipe of operations is an expression.

Spot it

A workshop charges a fixed setup fee plus twice the number of items made. Which part is the variable, and what does an expression describe?

04 Worked example

05 Why and when

Variables let one rule describe many cases instead of repeating the same arithmetic. An expression gives a quantity, but does not by itself claim that it equals another quantity. Use an equation when you need to state that two quantities match.

06 How to arrive at it

Convention

We need a short written label for a value that changes. Rewriting a long description each time is cumbersome, so mathematics uses symbols such as x. The choice of letter is a convention: the role and rule matter, not which letter is chosen.

07 In an LLM

A feed-forward network contains expressions built from inputs, learned weights and offsets. Conceptually, a neuron can include a weighted sum followed by an activation; a single expression is only a simplified piece of a neural network, not a complete language model.

Teach it back

Analogy: a variable is a labelled box; it breaks when we mistake the box for a fixed value instead of a placeholder.

Common misconception: a variable is not always an unknown to solve for—it can represent any changing input.

Equations

An equation links quantities; it is not an instruction to calculate from left to right.

01 Meaning

Imagine a fixed total split between two containers. If the combined amount is four units, many pairs of amounts fit. The written statement x + y = 4 says the two quantities add to four. Here x and y are unknowns, and every pair that makes the statement true is a solution.

02 Picture

One equation with two unknowns gives a whole line of choices. A second independent equation can narrow the choices to their shared point.

Explore a fixed total and a second rule

Move x along the first rule.
For this x, the matching y is calculated below.

03 Real life

A fixed budget can be split between two purchases; a container's total volume can be shared by two ingredients; mass entering and leaving a system can be balanced. The same mathematical structure says that combined quantities must equal a fixed total.

Recognition rule: if two descriptions are asserted to have equal value, read the equals sign as “has the same value as.”

Spot it

Two jars hold a combined four litres. A note says that the first jar contains the same amount as the second. What does each relationship constrain?

04 Worked example

05 Why and when

An equation lets us describe a constraint and reason about every value that meets it. One equation may leave multiple possibilities; a system of equations adds constraints. If the equations are redundant or contradictory, they may not give one unique point.

06 How to arrive at it

Motivated

To describe a balance, we need to compare two quantities without implying that one must be computed first. Equality is a compact way to say they have the same value. The sign is a convention, while the balance idea motivates it.

07 In an LLM

For a next-token probability distribution, probabilities over the model's vocabulary sum to one. Prompt and generated tokens must also fit within a model's context window. In a simplified neuron, weighted sum plus bias can define a decision boundary such as w·x + b = 0; this is a geometric analogy for one linear boundary, not a description of an entire model.

Teach it back

60-second explanation: An equation says two quantities match. One equation can leave choices open; another independent condition can select a shared solution.

Analogy: a balanced scale; the analogy is limited because algebra can describe quantities that are not physical objects.

Whiteboard: draw a line of possible splits, label x + y = 4, then add a second line and mark the intersection.

  • Does the equals sign mean “the answer comes next”? No, it states equality.
  • Can one equation have many solutions? Yes.
  • Will two equations always give one solution? No; they may be parallel, identical, or inconsistent.

Common misconception: x + y = 4 does not determine one pair by itself.

Functions and graphs

A function is a rule with one output for each allowed input; a graph makes the relationship visible.

01 Meaning

Think of a function as a dependable machine: supply an input, and it returns exactly one output. We can write that rule as y = f(x), where f names the rule and x is the input. A graph plots the input-output pairs.

02 Picture

Change the input and trace the output

The graph updates with the rule.
Choose a rule and input to see its output.

03 Real life

A recipe maps servings to ingredient amounts; a unit converter maps a temperature reading to another scale; a distance-time record maps time to position when each time has one position.

Recognition rule: if every allowed input has exactly one assigned output, you have a function. One output cannot map back to two values for the same input.

Spot it

A parking garage charges a fixed fee plus a rate for each hour. What is the input, and what is the output?

04 Worked example

05 Why and when

Functions let us describe a rule once and ask what it predicts for many inputs. If a real system has several possible outputs for the same input, a single-valued function may not model it directly; use a richer description such as a set-valued rule or a probability distribution.

06 How to arrive at it

Derived

To make predictions consistently, an input must not leave us unsure which output the rule assigns. Requiring exactly one output for each allowed input gives the defining condition for a function.

07 In an LLM

At a high level, a language model maps a tokenized context to scores or a next-token probability distribution. A transformer is a composition of many operations; calling it a function is accurate mathematically, while the simple input-output picture hides its internal structure.

Teach it back

60-second explanation: A function assigns exactly one output to each allowed input. Its graph shows those assignments as points.

Analogy: a vending machine; real machines can fail or have ambiguous selections, which the mathematical rule abstracts away.

Whiteboard: draw an input arrow, a rule box, an output, then graph several input-output pairs.

  • Can two inputs have the same output? Yes.
  • Can one input have two outputs? Not for a function.
  • Is every relation a function? No.

Common misconception: a function is not just a formula; it also has allowed inputs and a rule that returns one output.

Slope and linear functions

A straight line changes by the same vertical amount for every equal horizontal step.

01 Meaning

Picture a ramp: its steepness compares how much it rises with how far it runs. That rate is the slope. A linear function has the same slope everywhere. In y = mx + b, m is the slope and b is the vertical intercept.

02 Picture

Adjust the ramp

The rise and run are shown on the graph.
The line's steepness is its rise divided by its run.

03 Real life

Slope describes a road's grade, the rate a tank fills per minute, or the constant price added per item. In each case, compare the change in one quantity with the change in another.

Recognition rule: when equal changes in the input produce equal changes in the output, the plotted relationship is a straight line and the rate is its slope.

Spot it

A ramp rises by the same height each time you move the same distance forward. Which property stays constant?

04 Worked example

05 Why and when

Slope compresses a steady relationship into one number, making comparisons and predictions simple. It is not appropriate when the rate changes substantially; a curve or a piecewise rule may fit better.

06 How to arrive at it

Derived

To compare steepness across differently sized steps, use change in output divided by change in input. If that ratio is the same between any two points, the relationship is linear and the ratio is its slope.

07 In an LLM

A simplified neuron can compute a weighted sum plus a bias, such as w·x + b. The bias shifts the boundary; in a two-coordinate picture, setting the expression to zero gives a line. Modern networks use many dimensions and nonlinear operations, so this line picture is only a local/simple component view.

Teach it back

60-second explanation: Slope is rise divided by run. A linear function has a constant slope and can be written y = mx + b.

Analogy: a ramp; unlike an ideal straight ramp, real roads can change grade.

Whiteboard: draw axes, a straight line, a right-angle rise/run marker, and label the intercept.

  • Can slope be negative? Yes, if output falls as input rises.
  • What does zero slope mean? A horizontal line.
  • What does b change? Where the line crosses the vertical axis.

Common misconception: slope is not just “how high”; it is a ratio of changes.

Further reading: MML Chapter 1 (motivation).

Exponents, growth and decay

Repeated multiplication describes change by a constant factor over equal steps.

01 Meaning

Imagine an amount that is multiplied by the same factor at every step. The base is that repeated factor; the exponent counts how many steps. When the factor is above one, the amount shows growth; when it is a positive fraction below one, it shows decay.

02 Picture

Compare repeated growth and decay

The rate is a multiplier per step.
Change the multiplier to compare the two patterns.

03 Real life

Compound interest multiplies a balance by a repeated factor; a substance may lose the same fraction in each equal time interval; a chain reaction can produce increasing counts. These are models whose assumptions should be checked against the situation.

Recognition rule: if equal steps multiply the amount by a stable factor, expect an exponential pattern rather than a constant added amount.

Spot it

A battery retains the same fraction of its charge during each equal time interval. Does that describe a fixed amount removed or a repeated factor?

04 Worked example

05 Why and when

Exponents make repeated multiplication compact and reveal how a stable proportional change accumulates. They can mislead when the factor changes or the process is constrained; use measured data and a more suitable model when assumptions fail.

06 How to arrive at it

Derived

If each step multiplies by r, then after successive steps the amount is multiplied by r repeatedly. Repeated multiplication is precisely what a power represents, so the exponent counts the number of steps.

07 In an LLM

Softmax uses exponentials of scores before normalizing them into a probability distribution. This is a specific use of exponentiation; it does not mean token counts or model capability generally follow an exponential growth law.

Teach it back

60-second explanation: A power represents repeated multiplication. A constant multiplier above one grows an amount; a multiplier between zero and one shrinks it.

Analogy: a stack of paper doubled repeatedly; physical thickness and resources eventually limit the idealized pattern.

Whiteboard: show an initial amount, multiply by r once, then repeat and label the step count as the exponent.

  • Is 2 + 2 + 2 exponential? No, it is repeated addition.
  • What if the multiplier is less than one? The amount decays.
  • Does a real process continue forever? Usually not.

Common misconception: “exponential” does not just mean “fast”; it means the amount changes by a repeated factor in the model.

Logarithms

A logarithm counts multiplication steps and turns products into sums.

01 Meaning

A logarithm asks: how many times must we multiply by a chosen log base to reach a positive number? For example, a base of two reaches eight in three equal multiplication steps. Logs also compress wide ranges: equal multiplicative changes become equal additive steps on a log scale.

02 Picture

Count the repeated multiplications

Choose a base and a value.
The logarithm counts the exponent that reaches the value.

03 Real life

Decibels compare sound intensity on a logarithmic scale; pH compresses hydrogen-ion concentration; earthquake magnitude, musical octaves and bits also use logarithmic relationships, with different conventions and reference quantities.

Recognition rule: if a scale assigns equal steps to equal multiplicative ratios, think logarithm and check the scale's base and reference.

Spot it

A display uses equal steps to represent values that multiply by the same factor each time. What kind of scale is likely being used?

04 Worked example

05 Why and when

Logarithms make repeated multiplication easier to reason about and let products become sums: log(ab) = log(a) + log(b) for positive a and b. They are useful for wide ranges and multiplicative relationships, but they are undefined for non-positive inputs in the real-valued setting.

06 How to arrive at it

Derived

Exponentiation answers “what value after n repeated multiplications?” To reverse that question and recover the step count from the value, define the logarithm. Choosing a base sets the counting unit; base 2 counts doublings, while other bases give different units.

07 In an LLM

Models commonly compute and report log-probabilities. A language-model training objective often uses cross-entropy; its average in nats can be exponentiated to obtain perplexity. Using base two expresses information in bits rather than nats; details depend on tokenization and evaluation setup.

Teach it back

60-second explanation: A logarithm counts how many multiplications by a base reach a value. It reverses exponentiation and turns products into sums.

Analogy: counting rungs on a ladder of powers; the rung spacing depends on which base you choose.

Whiteboard: list powers of a base, mark a target value, then count the exponent and rewrite the question as a logarithm.

  • Can a real logarithm take a negative input? No.
  • Does changing the base change the answer? Yes, by a unit conversion.
  • Why do logs help with large ranges? They represent multiplicative ratios as additive steps.

Common misconception: a logarithm is not a mysterious operation; it asks for the exponent.

Further reading: MML Chapter 1 (motivation).

Σ notation

The capital Greek letter sigma is a compact instruction to add a sequence of terms.

01 Meaning

When a list is long, writing every plus sign is tiring. Sigma notation says where to start, where to stop, and what term to add. The summation below adds aᵢ as i runs from one to n; each aᵢ is the term at index i.

xᵢ identifies an indexed value; aᵢ identifies the term being added.

02 Picture

Expand a short sum

The sequence here is one, two, three, and so on.
Choose the last index to add the terms.

03 Real life

A store totals prices in a basket; a sensor system totals readings over a window; an analyst adds errors across examples to form a loss. In each case, many contributions combine into one total.

Recognition rule: if you see a large plus-separated list with a repeated pattern, Σ is shorthand for the same addition, not a new operation.

Spot it

A report adds each day's measured usage over a selected period. What does the summation index help you track?

04 Worked example

05 Why and when

Sigma notation keeps repeated patterns readable and makes bounds explicit. It can hide what the terms mean if the index and expression are not defined, so expand a short sum when the pattern is unfamiliar.

06 How to arrive at it

Convention

Repeated addition needs a compact record of the term rule and the index range. Σ was adopted as a visual shorthand for summing; the particular symbol is conventional, while the specified terms and bounds determine the result.

07 In an LLM

A weighted sum adds input-weight products. Training objectives commonly aggregate a loss across tokens or examples. The exact reduction—sum, mean, masking, and weighting—depends on the stated objective and implementation.

Teach it back

60-second explanation: Σ means add the listed terms. Its lower and upper bounds tell which indices to include, and the expression defines each term.

Analogy: a shopping basket total; it is limited because a mathematical sequence may use signed, fractional, or abstract values.

Whiteboard: expand a short sum into terms, circle the index bounds, and write the same expression with Σ.

  • Is Σ multiplication? No, it denotes addition.
  • Can the index start at zero? Yes, if the bounds say so.
  • Does sigma tell us what the terms mean? Only when the term rule is defined.

Common misconception: the index variable is a counter, not necessarily a quantity being measured.

Ratios, percentages and averages

These are three ways to compare, scale, or summarize quantities.

01 Meaning

A ratio compares quantities by division. A percentage expresses a ratio per hundred. An average spreads a total evenly across the number of values.

02 Picture

Scale a percentage and share a total

Both answers update from the controls.
The percentage amount and sample average are calculated below.

03 Real life

Ratios compare ingredients in a recipe; percentages describe a discount relative to an original price; averages summarize a group of measurements. A mean can hide variation, so it is not a complete description of a dataset.

Recognition rule: division comparing two amounts suggests a ratio; “out of one hundred” suggests a percentage; “share the total equally” suggests an arithmetic mean.

Spot it

A class reports one score representing the total points shared evenly among all submitted papers. Which summary is being used?

04 Worked example

05 Why and when

Ratios compare scale, percentages put comparisons in familiar units, and averages provide a simple center. A ratio depends on units and order; a mean is sensitive to extreme values. Choose a median or show the full distribution when that matters.

06 How to arrive at it

Convention

Dividing quantities gives their relative size. Multiplying a ratio by one hundred expresses it per hundred, a useful shared scale. Dividing a total by its count defines the equal share called the arithmetic mean.

07 In an LLM

Evaluation commonly reports an average loss across a stated set of tokens or examples. Reporting percentages can make a ratio easier to read, but the denominator and aggregation rule must be stated. These are measurement choices, not a special property of language models.

Teach it back

Analogy: share a bowl evenly to understand an average; the average does not tell you whether the portions were actually equal.

Common misconception: an average does not imply that every value is close to it.

Further reading: MML Chapter 1 (motivation).

Sine and cosine

On a circle of radius one, cosine and sine are the horizontal and vertical coordinates.

01 Meaning

Imagine turning a pointer around a circle centered at the origin. The angle tells how far it has turned. On the unit circle, the horizontal coordinate is cosine and the vertical coordinate is sine.

02 Picture

Turn the pointer around the unit circle

Coordinates update as the angle changes.
Measured in degrees
Cosine is the horizontal coordinate; sine is the vertical coordinate.

Radians measure angles by circle arc length; degrees divide one full turn into equal units. The slider converts the selected degree value to radians before calculating.

θ labels the angle from the positive horizontal direction.

03 Real life

A wheel's position repeats as it turns; a pendulum's horizontal and vertical positions vary with its angle; a shadow's length changes with orientation. Sine and cosine describe coordinates or projections in these cyclic settings.

Recognition rule: when a rotating direction or repeating cycle is involved, sine and cosine can describe its coordinates. Check whether the angle unit is degrees or radians.

Spot it

A point moves around a circular track. Which coordinate tells its left-right position, and which gives its up-down position?

04 Worked example

05 Why and when

Sine and cosine turn an angle into coordinates and are useful for periodic motion and projections. They are not a general-purpose relationship for every changing quantity; use a model that matches the geometry or periodicity of the problem.

06 How to arrive at it

Convention

For a rotating pointer, track its horizontal and vertical coordinates as the angle changes. Naming those coordinate functions cosine and sine is a mathematical convention; their geometric meaning comes from the circle.

07 In an LLM

The connection here is conceptual preparation: a dot product compares directions using cosine of the angle between vectors. Some positional encodings use sinusoidal functions, as described by Vaswani et al. (2017) in “Attention Is All You Need”; this circle widget is not itself a model component.

Teach it back

Analogy: a rotating clock hand; the circle's coordinates track its horizontal and vertical position.

Common misconception: sine is not always “opposite over hypotenuse” as a memorized triangle ratio; the unit-circle coordinate definition generalizes the idea.

Reading mathematical notation

Small marks around symbols carry structure: labels, powers, predictions, and logical scope.

01 Meaning

Notation is a compact language. A subscript labels a component, a superscript may indicate a power, a hat often marks an estimate, and set membership says an object belongs to a collection. A quantifier tells whether a statement applies to every element or only some.

02 Picture

NotationHow to read it
“x sub one”: a labelled component, not x multiplied by one.
“x squared”: a power in this context.
“y hat”: often a predicted or estimated y; definitions vary by author.
x belongs to the collection S.
For every x in S.
Bold x Often indicates a vector, though notation varies by text.

x₁ marks a first component; ∀ means “for every”; ∈ means “is an element of.”

03 Real life

Labels on boxes distinguish ingredients; a raised number can encode repeated multiplication; a hat may mark a forecast rather than an observed value. The same mark can mean different things in different contexts, so definitions matter.

Recognition rule: pause at a small mark and ask what role the surrounding definition assigns it before calculating.

Spot it

A vector is written in bold, and its entries carry small numbered labels below the line. What do bold type and the lower labels usually signal?

04 Worked example

05 Why and when

Notation lets a short expression carry relationships and logical scope. Dense notation can hide assumptions, and symbols are not perfectly universal; consult the local definitions and expand a statement into words when needed.

06 How to arrive at it

Convention

Writers need a compact way to label components, powers, predictions, and collections. Subscripts, superscripts, hats, bold type and logical symbols are conventions; the surrounding text specifies their exact role.

07 In an LLM

An embedding is represented mathematically as a vector of numbers, and model papers use subscripts to distinguish tokens, positions and components. The details depend on each paper's notation; no single typography rule is universal.

Teach it back

Analogy: notation is like labels and punctuation on a map; it helps you read structure, but the map legend still matters.

Common misconception: a superscript does not always mean “raise to a power”; context can assign another role.
