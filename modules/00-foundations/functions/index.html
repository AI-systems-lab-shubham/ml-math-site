Functions and graphs

A function is a rule that gives exactly one output for each allowed input. A graph makes the rule visible.

01 Meaning

Think of a vending machine. Press the same button and you always get the same snack. The button you press is the input; the snack that drops is the output. A function is any rule that behaves like that: one input in, exactly one output out, the same every time.

We write the machine as a name and a recipe. For “double it, then add 1”:

f(x) = 2x + 1

Read f(x) as “the output of f when the input is x”. The letter f is just the machine's name.

02 Picture

A graph draws the machine's whole behaviour: for each input, mark a point at the height of its output. Choose a rule, then slide the input and watch the point trace the curve.

A function as a machine and as a graph

03 Real life

  • A price list: item in, price out.
  • A speedometer: moment in time in, speed out.
  • A taxi meter: distance in, fare out.
  • A thermostat dial: setting in, target temperature out.

Recognition rule. If asking the same question twice must give the same answer, and the answer depends on something you can vary, think “function”. If the same input could give different outputs, it is not one.

Spot it. Which of these is a function from the first thing to the second?

04 Worked example

05 Why and when

Naming a rule lets us treat “how the output depends on the input” as one object that we can draw, compare, combine and improve. Without the idea you would have only a pile of separate facts.

It fits whenever each input has a single predictable output. It does not fit a rule where the same input can give different outcomes, such as a dice roll. For that you describe a spread of possible outputs with probabilities (Module 5).

06 How to arrive at it

● Motivated

  1. The requirement. A machine you can rely on: tell it what you put in and know what comes out.
  2. Obvious candidates. A complete list of pairs; a formula; a drawing.
  3. The catch. What if an input was allowed to give two different outputs?

Predict: what goes wrong if one input can produce two outputs?

I have made my prediction: show the reasoning

You could no longer say what “the” output is, so you could not calculate with it or draw a single curve. Requiring exactly one output per input is what keeps the machine dependable. It is tagged Motivated because it is a very good fit for that need, but other notions (relations that allow several outputs) exist and are useful elsewhere.

07 In an LLM

Seen from outside, a language model is a function. Its input is the sequence of tokens so far; its output is a probability for every token in the vocabulary being the next one. Feed it the same tokens and the same settings, and the function gives the same probabilities.

Simplified. When you chat, the system then samples a token from those probabilities. That random step happens outside the function, which is why the same prompt can produce different replies. Sampling comes in Module 5.

Explain it back

A function is a rule that takes an input and gives one definite output, the same every time. If an input could give two outputs we could not say what the output is, so we could not calculate or draw it as one curve.

Teach it

60-second explanation

“A function is a vending machine for numbers. You press a button, the machine follows its rule, and out comes one result. Press the same button again, same result. The graph is just a picture of every button and what it gives: left to right the input, up and down the output.”

Everyday analogy

A recipe: ingredients in, dish out. Where it breaks down: a real recipe can turn out differently each time; a function never does.

Whiteboard sequence

  1. Draw a box with an arrow in and an arrow out.
  2. Write the rule inside: double, then add 1.
  3. Feed in 0, 1, 2 and write the outputs.
  4. Draw axes and plot the three points.
  5. Join them; ask what happens between the points.

Questions learners ask

Is f(x) the same as f times x? No. f(x) means “the output of f at x”. The brackets mean “apply”.

Can two inputs give the same output? Yes. Both 2 and −2 give 4 under “multiply it by itself”. A function only forbids one input giving two outputs.

Why draw a graph at all? Because patterns such as steepness or turning points are easier to see than to read from a table.

Common misconception

“A function must have a formula.” A lookup table or a learned model is a function too, as long as each input has one output.
