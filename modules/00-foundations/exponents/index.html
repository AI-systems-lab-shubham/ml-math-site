Exponents, growth and decay

Repeated multiplication by the same number describes change proportional to size.

01 Meaning

Fold a sheet of paper in half, then in half again. Each fold doubles the thickness. Adding the same amount each time makes steady progress; multiplying by the same number each time makes progress that speeds up (or slows down) with the size.

Writing “2 × 2 × 2 × 2 × 2” gets tiresome, so we count the copies with a small raised number, the exponent. The number being multiplied is the base:

2⁵ = 2 × 2 × 2 × 2 × 2

If a quantity starts at a and is multiplied by a factor r at every step, after n steps it is

a rⁿ

When r is bigger than 1 this is growth. When r is between 0 and 1 it is decay.

02 Picture

Burgundy bars multiply by the factor at every step. Ochre diamonds show what you would get by adding the first step's change every time instead. Raise the number of steps and watch which one runs away.

Multiplying versus adding

03 Real life

  • A lily patch that doubles its coverage of a pond each day.
  • Savings with compound interest: each year's interest is added to the base for next year's.
  • A hot drink cooling toward room temperature: the gap shrinks by about the same fraction each minute.
  • A radioactive material halving over each half-life.

Recognition rule. If each step multiplies by the same factor, think exponent. If each step adds the same amount, think line. A curve that gets steeper as it grows, or flatter as it shrinks, is a sign of multiplying.

Spot it. A pond's lily patch covers twice as much surface each day. How does the coverage change?

04 Worked example

Predict, then reveal

Write the sequence one step at a time: 1, then double it, then double again, and so on.

05 Why and when

The exponent compresses “multiply this many times” into one symbol and exposes how startlingly fast repeated multiplication runs away, or fades. Without it, long products are error-prone and the speed is hidden.

It fits changes proportional to current size. It does not fit steady changes (use a line) or processes that level off (those need other curves).

06 How to arrive at it

✓ Derived

  1. The requirement. The change at each step should be in proportion to the current amount.
  2. Obvious candidate. Add a fixed amount each step.
  3. Why it fails. A fixed addition ignores the size: 10 and 10,000 would grow by the same amount.

Predict: what operation makes the change scale with the size?

I have made my prediction: show the reasoning

Multiplying by a fixed factor r changes an amount of size A by A × (r − 1), which is proportional to A. Repeating that n times from a start of a gives a·r·r·…·r, which we abbreviate a·rⁿ. The form is forced by the requirement, so it is Derived.

07 In an LLM

With a vocabulary of V tokens, the number of possible sequences of n tokens is Vⁿ. In the original Transformer's English–German translation experiment, the shared vocabulary was about 37,000 tokens; the English–French experiment used a 32,000 word-piece vocabulary (Vaswani et al., 2017). Even a sequence of just two tokens already has … possibilities.

That explosion is why a language model cannot store a table of answers for every sequence. It computes a probability from a formula instead.

Simplified. This is a counting argument, not a description of how any particular model works. Many sequences are nonsense, and models never visit most of them.

Explain it back

Adding a fixed amount changes everything by the same step, so the graph is a line. Multiplying by a factor changes things in proportion to their size, so the steps get bigger as the amount grows (or smaller as it shrinks). The exponent counts how many times the factor has been multiplied in.

Teach it

60-second explanation

“Adding is like walking: the same distance every step. Multiplying is like a snowball rolling downhill: the bigger it gets, the more snow it picks up. We write ‘multiply 5 times’ as a small 5 above the number. Doubling just ten times from 1 gets you past a thousand.”

Everyday analogy

Folding paper. Where it breaks down: real paper cannot be folded more than a handful of times, so the pattern stops being physical long before the formula does.

Whiteboard sequence

  1. Write 1, 2, 4, 8, 16 in a row and arrows labelled ×2.
  2. Below it write 1, 2, 3, 4, 5 with arrows labelled +1.
  3. Draw both as bars.
  4. Label the doubling bars 2⁰ … 2⁴.
  5. Ask: which one is ahead after 10 steps?

Questions learners ask

What is 2⁰? 1: zero multiplications leaves the start untouched.

Can an exponent be negative? Yes; it means dividing instead of multiplying. We meet that with logarithms.

Why does decay never reach zero? Halving leaves half of what remains, which is never nothing.

Common misconception

“2⁵ means 2 × 5.” It means 2 multiplied by itself five times: 32, not 10.
