Linear algebra

Lists of numbers that can also be arrows, and tables of numbers that act as machines. Four ideas, each from a picture first, then the symbols, then where it shows up inside a language model.

Terms with a dotted underline are a tap or hover away from a plain-language and a mathematical definition. Systems of equations, span and linear transformations come in the next part.

Arrows are drawn in 2D only. A page is flat, so every picture here has two entries. The ideas that carry over unchanged to any number of entries are adding, scaling, dot products and matrix multiplication: each is a rule applied entry by entry, so it does not care how many entries there are. What cannot be drawn is anything with more than three entries (a language model uses hundreds), so treat the arrow as a guide for your intuition and the entry-by-entry rule as the definition.

Vectors: arrows and lists

A vector is a list of numbers in a fixed order. With two or three entries it is also an arrow.

01 Meaning

Tell a friend where a hidden treasure is: “walk 3 steps east, then 2 steps north”. Two numbers, in a fixed order, describe the whole trip. The list (3, 2) is a vector. Swap the order and you get (2, 3), a different trip.

The same trip is also an arrow. Start at the origin, draw a straight arrow to the point 3 across and 2 up. Two pictures, one object: the list is easy to calculate with, the arrow is easy to see.

Each number in the list is a component (or entry), found by its position. Counting from 1, the vector below has entries v₁, v₂, …, vₙ, and n is its dimension: how many numbers it holds.

v = (v₁, v₂, …, vₙ)

02 Picture

Change the entries, or drag the tip of the arrow. The blue dots show how far across, the teal dots how far up. Then switch to 3 or 5 entries and see what stays and what has to go.

One vector, two pictures

03 Real life

  • Where you are on a map: latitude and longitude, two numbers in a fixed order.
  • Wind: a speed and a direction, which is exactly an arrow.
  • A colour on a screen: how bright its red, green and blue lights are, three numbers in order.
  • One customer's record in a shop's database: (visits per month, items per visit, average spend).

Recognition rule. If a thing needs several numbers in a fixed order to describe it, think “list”. If it also has a size and a direction, think “arrow”.

Spot it. A drone is told to fly 30 m east and then 40 m north. How should its trip be stored so that nothing is lost?

04 Worked example

Predict, then reveal

The small 3 is a position, not a number to multiply by. Count to the third entry from the left.

05 Why and when

One name for a whole list lets you write one rule that works on every entry at once. Without it, a record with 512 numbers would need 512 names.

Use a vector when position carries meaning and the entries belong together. Be careful when the entries use different units, such as an age and an income: the list is still a fine record, but the arrow picture and the idea of “how far apart” then mix unlike things.

What carries over to many dimensions. Everything we do with entries (adding, scaling, taking dot products) works for any dimension. What cannot be drawn: more than three entries. So the arrow is a way to build intuition, not a requirement.

06 How to arrive at it

◆ Convention

Both the list and the arrow are choices of how to write down the same trip. We write the entries in a column or a row, number them from 1, and write bold or with an arrow on top. None of that is forced; another book can do it differently and the maths is unchanged. What is not a choice is that the order of entries must be fixed, or you could not compare two vectors.

07 In an LLM

A language model does not work with words directly. It first turns each token into a vector of numbers, called an embedding. In the original Transformer base model that vector has … entries (Vaswani et al., 2017, §3.4 and Table 3).

Made-up illustration numbers, not real model weights. A token such as “cat” might be stored as a list like …. That is only … entries instead of …, and the numbers are invented to show the shape of the idea.

Simplified. The embedding values are learned during training. Individual entries do not have a neat meaning you can read off, such as “catness”. The useful fact is that the list is a vector, so the rules of this module apply to it.

Explain it back

The list gives the arrow's coordinates and the arrow gives the list a place in space, so they are two views of one thing. Once there are more than three entries there is no room to draw the arrow, but the list and every entry-by-entry rule still work.

Teach it

60-second explanation

“A vector is a list of numbers where the order matters. Say ‘3 east, 2 north’. That is two numbers, and it is also an arrow from where you start. If the list has more numbers we cannot draw it, but we can still add and scale it, because we do it one number at a time. A language model turns every word-piece into a long list like this, hundreds of numbers, so it can do arithmetic on words.”

Everyday analogy

A postal address: street number, street, city, in a fixed order. Where it breaks down: you cannot meaningfully add two addresses, but you can add two vectors.

Whiteboard sequence

  1. Draw two axes and mark the origin.
  2. Write (3, 2) and plot the point.
  3. Draw the arrow from the origin to the point.
  4. Write (2, 3) and draw it too, to show order matters.
  5. Write a 5-entry list and say “no picture, same rules”.

Questions learners ask

Is a vector the arrow or the list? Both are the same object seen two ways. The list is how we compute; the arrow is how we picture.

Does the arrow have to start at the origin? For this module, yes. Moving an arrow without turning it does not change what it means as a displacement, which we use when adding.

What is a 1-entry vector? A single number written as a list. It is the case where the arrow sits on a line.

Common misconception

“A vector is an arrow, so I need a picture.” It is a list first. Most of the vectors in machine learning have too many entries to draw.

Further reading: MML Ch 2.1 and 2.4 (vector spaces, vectors as lists).

Adding, scaling and combining vectors

Two moves build new vectors from old ones: stretch an arrow, and join arrows tip to tail.

01 Meaning

Walk 3 blocks east and 1 north. Then walk 1 block west and 2 north. Doing the two walks one after the other is vector addition: put the second arrow where the first one ends, and the total trip is the arrow from the very start to the very end. In numbers, add the first entries together and the second entries together.

Scaling is doing the same walk several times: twice as far in the same direction, or half as far. A negative number sends you backwards. Every entry is multiplied by the same scalar, which is just the name for an ordinary number when it is used to scale a vector.

Put the two moves together and you get a linear combination: scale some arrows, then add them.

c₁a + c₂b

02 Picture

The dashed arrows are a (teal) and b (blue). Choose c₁ and c₂. The thick teal arrow is c₁a, the thick blue arrow starts at its tip, and the burgundy arrow from the origin to the very end is the sum. Use the “Build it up” choice to see one piece at a time.

Scale two arrows, then add them tip to tail

03 Real life

  • A boat steers across a river while the current pushes it downstream: the path over the ground is the sum of the two velocities.
  • Two people push a heavy box in different directions: the net push is the sum of the two force arrows.
  • Doubling a recipe multiplies every ingredient amount by 2: scaling a list.
  • Mixing paint, three parts blue to one part yellow, is a combination of two colour recipes.

Recognition rule. If two effects act together and each has a size and a direction, add them. If the same effect is made bigger, smaller or reversed, scale it.

Spot it. A boat heads (4, 0) km/h east through still water. A current pushes it (0, 3) km/h north. Which operation gives its motion over the ground?

04 Worked example

Predict, then reveal

Double the first entry of a, then subtract the first entry of b. Mind the signs.

05 Why and when

Adding and scaling are the only two things a vector space needs, and they build a huge family of vectors from a few. A question like “which arrows can I reach from a and b?” is a question about linear combinations (explored fully in the next part).

Adding vectors (and so linear combinations) needs the same number of entries: you cannot add (1, 2) to (1, 2, 3). Scaling one vector does not. Adding also assumes entries mean the same thing in each vector, position by position.

Many dimensions. Both rules work unchanged for any number of entries. Only the arrow picture runs out.

06 How to arrive at it

✓ Derived

  1. The requirement. Adding two arrows must give the arrow of doing one walk and then the other.
  2. Obvious candidates. Add entry by entry, or multiply entry by entry, or keep the longer arrow.
  3. Why most fail. Walk 3 east then 1 east: you must end 4 east, so entries must add. East and north steps do not interfere, so each entry adds on its own.

Before you open the next part, predict: what should (3, 2) + (3, 2) be, and what single move gives the same result?

I have made my prediction: show the reasoning

Doing the same walk twice gives (6, 4). That is each entry doubled, so doubling is just repeated adding. Scaling by 2 is forced to be “multiply every entry by 2”. Scaling by a fraction is forced the same way (half the walk), and a negative number is forced to mean walking backwards. That is why this card is Derived: addition and scaling fall out of what a walk is.

07 In an LLM

  • Positions are added to token vectors. The original Transformer adds a position vector to each token's embedding, which works because both have the same dimension (Vaswani et al., 2017, §3.5).
  • Layers add their output to their input. Each sub-layer's output is added to the vector that went into it, then normalised (Vaswani et al., 2017, §3.1). This is vector addition, applied once per sub-layer.

Made-up illustration numbers, not real model weights. Take a token vector … and a layer output …. Their sum is …, entry by entry.

Simplified. Real vectors have … entries, and the paper applies layer normalisation after the addition, which this card does not cover.

Explain it back

Walk along a twice as far, then walk along b backwards. East steps and north steps do not affect each other, so the total east is the sum of the east parts and the total north is the sum of the north parts. That is entry-by-entry adding.

Teach it

60-second explanation

“There are two moves. Scaling stretches an arrow: times 2 makes it twice as long, times −1 flips it. Adding puts one arrow after another: go along the first, then along the second. In numbers both are easy: scale multiplies every entry; add adds entries in the same position. Mix them and you get a recipe such as 2a minus b.”

Everyday analogy

Following two sets of directions in a row: “2 blocks that way, then 1 block back along the other road”. Where it breaks down: real walks can be blocked by buildings; arrows can pass through anything.

Whiteboard sequence

  1. Draw a and b from the origin.
  2. Draw 2a, longer in the same direction.
  3. Draw −b from the tip of 2a, pointing the other way.
  4. Draw the arrow from the origin to the end.
  5. Write the same thing with numbers, entry by entry.

Questions learners ask

Why does the order of adding not matter? Adding entries is ordinary number adding, which does not care about order. As walks, either order reaches the same place.

What does scaling by 0 give? The zero vector, an arrow of no length at the origin.

Can I add vectors of different dimensions? No. There would be nothing to pair some entries with.

Common misconception

“Adding two vectors adds their lengths.” Not in general. Two arrows at an angle give a total shorter than the sum of their lengths.

Further reading: MML Ch 2.4 (vector spaces) and Ch 2.5 (linear combinations in the next part).

Matrices: tables and machines

A matrix is a table of numbers. It is also a machine that turns one vector into another.

01 Meaning

A bakery's recipe card lists grams of flour and sugar in one loaf, and in one cake. That is a small table with two rows (flour, sugar) and two columns (loaf, cake). A table like this is a matrix. Its shape is rows × columns, so this one is 2×2.

Now the machine view. Type in how many loaves and cakes you will bake, as the vector (loaves, cakes). Out comes the total flour and sugar. Each column says what one of that product contributes, and you scale it by how many you make. That is exactly “scale some vectors and add”, from the last card.

The columns also have a picture. The two unit arrows (1, 0) and (0, 1) go in; the matrix sends them to its first and second columns. Every other input is a mix of those two unit arrows, so its output is the same mix of the two columns.

Mv = v₁(column 1) + v₂(column 2)

02 Picture

Edit the six numbers. The dashed arrows are the two columns of M. The thick teal arrow is v₁ times column 1, the thick blue arrow starts at its tip and is v₂ times column 2, and the burgundy arrow is the output Mv. Change a matrix entry and watch the column arrows, and Mv, move together.

A matrix as a machine: its columns are where the unit arrows land

What a matrix does to the whole plane at once (rotating, stretching, shearing) is explored fully in the next part.

03 Real life

  • A recipe table: ingredients in each dish, turned into total ingredients for a menu.
  • A currency table: amounts in euros and pounds in, the total in dollars out.
  • A spreadsheet of monthly sales by region, read as a table.
  • A graphics program that shrinks or turns a picture: every point goes in, a new point comes out.

Recognition rule. If each output is a weighted total of the inputs, and the weights never change, think “matrix”.

Spot it. A table lists grams of flour and sugar in one loaf and in one cake. You type how many loaves and cakes you bake. What does the matrix-machine give back?

04 Worked example

Predict, then reveal

Take row 1 of M, which is (2, 1), and pair it with (3, 2): multiply matching entries, then add.

05 Why and when

A matrix packs many weighted totals into one object, and lets one symbol, M, stand for the whole machine. Without it you would write a separate formula for each output.

A matrix machine always obeys two rules: doubling the input doubles the output, and the output for a sum is the sum of the outputs. So it cannot square a number, take a maximum or apply a curve. Those need something else, and a neural network adds them between matrices.

It also does not need to be square: a 3×2 matrix takes 2 numbers in and gives 3 out.

06 How to arrive at it

● Motivated

  1. The requirement. A rule where every output is a fixed weighted total of the inputs.
  2. Obvious candidates. A list of formulas, one per output, or a table of the weights.
  3. Why the table. The formulas all have the same shape, so only the weights differ. A table of weights holds everything and is easy to compute with.

Reading the table as columns of arrows comes from the previous card: the input is v₁ copies of one arrow plus v₂ of another. The choice to list rows first, then columns, is a Convention: “2×3” means 2 rows, 3 columns.

Before you open the next part, predict: if M sends (1, 0) to (2, 1) and (0, 1) to (−1, 1), where does it send (1, 2)?

I have made my prediction: show the reasoning

(1, 2) is 1 copy of (1, 0) plus 2 copies of (0, 1). So the output is 1 copy of (2, 1) plus 2 copies of (−1, 1): …. This is the default setting of the widget above.

07 In an LLM

A layer of a language model multiplies its input vector by a matrix of learned numbers, the weights. Two examples from the original Transformer base model (Vaswani et al., 2017, §3.2 and §3.3):

  • Each attention head builds its query, key and value vectors with learned projections: matrices that turn a …-entry vector into a …-entry one. In our column convention that matrix is …, so it has … entries.
  • The feed-forward layer widens a …-entry vector to … entries with one matrix (…, … entries) and narrows it back with another.

Simplified. The paper writes row vectors multiplied by matrices on the right (x W), so its matrices are the transposes of the ones here. The entry counts are the same. Biases and the non-linear step between the feed-forward matrices are left out.

Explain it back

Any input is some number of copies of the first unit arrow plus some number of copies of the second. A matrix machine scales and adds consistently, so the output is the same number of copies of the first column plus the same number of copies of the second. The two columns therefore fix the output for every input.

Teach it

60-second explanation

“A matrix is a table of numbers, but think of it as a machine. You put in a list of numbers and out comes another list. The recipe: each column of the table is what one unit of an input contributes. Scale each column by how much of that input you have, add them up, and that is the output. In a language model, the weights between layers are exactly such tables.”

Everyday analogy

A vending machine's price list combined with an order: each item has fixed prices at each shop, you choose quantities, and you read off the totals. Where it breaks down: real prices can change with quantity (discounts); a matrix cannot.

Whiteboard sequence

  1. Draw a 2×2 table and label rows and columns.
  2. Draw the two unit arrows (1, 0) and (0, 1).
  3. Draw where they land: the two columns.
  4. Pick an input, say (1, 2), and scale each column.
  5. Add the scaled columns to get the output.

Questions learners ask

Is a matrix just a spreadsheet? As a table, yes. As a machine, it also says how to combine rows and columns.

Why columns, not rows? With the input as a column vector, each input entry multiplies one column. Rows give the other, equally valid, view.

Can the output be longer than the input? Yes: a 3×2 matrix takes 2 numbers in and gives 3 out.

Common misconception

“A matrix is only a grid of numbers.” The grid is just how we write it down. What defines it is what it does to vectors.

Further reading: MML Ch 2.2 (matrices) and Ch 2.7 (linear mappings, in the next part).

Matrix-vector and matrix-matrix multiplication

Each entry of a product is a row dotted with a column. Chaining two machines is multiplying their matrices.

01 Meaning

In the last card, each output entry was “a row paired with the input, multiplied entry by entry, then added”. That is the dot product from the Σ card, and the whole recipe is the matrix-vector product: one dot product per row.

Back to x + y = 4. The one-row matrix [1 1] times the vector (x, y) is the single number x + y. For (x, y) = (1, 3) the product is …, so that pair solves the equation. Each equation is one row of weights; stack two equations and you have a two-row matrix. We will solve such systems in the next part. See Equations in Module 0.

Matrix multiplication chains two machines. Feed a vector through B, then through A. The single machine that does both in one go is AB, with vectors written as columns, as in most machine-learning texts. Its entry in row i, column j is the dot product of row i of A with column j of B. Each column of AB is A applied to the matching column of B.

For the dot products to exist, A must have as many columns as B has rows. Written with shapes, an m×n times an n×p gives m×p.

(AB)ᵢⱼ = Σₖ AᵢₖBₖⱼ

02 Picture

Pick an example, then step through the output entries. The outlined row of the left matrix and the outlined column of the right matrix pair up to fill one cell of the answer (burgundy). Try the two swap examples: the same two matrices in the opposite order give different answers. Try “shapes that do not fit” too.

Multiply, one output entry at a time

03 Real life

  • Total cost of a menu: ingredients per dish, then cost per ingredient, combined into cost per dish.
  • Chained unit conversions: kilometres to miles, then miles to something else, folded into one conversion.
  • Two photo filters applied in turn: one combined filter does the same job.
  • Population counts moving between cities each year: two years of moves, folded into one.

Recognition rule. If one weighted-total step feeds another, the two together are one matrix product, and the inner sizes must match.

Spot it. Table A gives kilograms of 3 ingredients in each of 2 dishes (3×2). Table B gives the price per kilogram of each ingredient in 2 shops (2×3). Which product gives the cost of each dish in each shop?

04 Worked example

Predict, then reveal

Row 2 of A is (4, 5, 6). Column 1 of B is (7, 9, 11). Pair them up and add.

05 Why and when

It lets you fold many chained steps into one machine, and it lets a computer do all the dot products in one regular pattern. Without the rule, “apply B then A” would need to be spelled out every time.

When it does not fit. The inner sizes must match. The order matters: AB and BA are usually different, and one can exist without the other. Multiplying matching entries of two same-shaped tables is a different operation, so do not confuse the two.

Cost. An m×n times n×p product takes m·n·p multiplications; the widget shows the count for each example.

06 How to arrive at it

✓ Derived

  1. The requirement. The product AB must be the machine that does B first, then A: (AB)v = A(Bv) for every v.
  2. Obvious candidate. Multiply matching entries of A and B.
  3. Why it fails. For P = [[1, 2], [3, 4]] and Q = [[0, 1], [1, 1]], applying Q then P to (1, 0) gives …. The matching-entries table sends (1, 0) to …. They disagree.
  4. Why the row-by-column rule remains. Write out A(Bv). Each entry of the result collects, from each column of B, a weighted sum of A's entries: a row of A paired with a column of B. That rule is forced by the requirement.

Before you open the next part, predict: for P and Q above, is PQ the same as QP?

I have made my prediction: show the reasoning

PQ is . Swapping the order, as the swap example in the widget shows, changes the answer in general: doing B then A is a different journey from doing A then B. Order matters because the first machine's output is the second machine's input.

07 In an LLM

  • Projections and feed-forward layers are matrix products. The query, key and value projections and the two feed-forward matrices all work by matrix multiplication (Vaswani et al., 2017, §3.2 and §3.3). A … matrix times one …-entry vector takes … multiplications.
  • A large share of the arithmetic. Much of a transformer's computation is matrix multiplication, including these layers and the attention-score step. We do not give a percentage here, since it depends on the model size and the sequence length.
  • Hardware. A GPU can do many independent multiplications and additions at once, which suits the many independent dot products inside a matrix product. This is general public knowledge about why such chips are used, not a statement about any company's systems.

Simplified. Real systems process many tokens at once, so the right-hand matrix has many columns instead of one. The attention scores multiply two matrices built from the same inputs (Module 2 and Module 10 build this up).

Explain it back

Each output entry pairs a row of the left matrix with a column of the right one, and pairing needs equal lengths, so the left's column count must equal the right's row count. The order matters because the product means “do the right one first, then the left one”, and the output of the first step is the input of the second.

Teach it

60-second explanation

“Multiplying a matrix by a vector means: take each row, pair it with the vector, multiply matching numbers and add. Multiplying two matrices means chaining two machines into one. To fill each cell of the answer, take a row from the left matrix and a column from the right matrix, pair them off and add. The sizes must fit: columns on the left equal rows on the right. And the order matters, because the right machine runs first.”

Everyday analogy

Two currency converters in a row: euros to pounds, then pounds to dollars. One combined converter does both. Where it breaks down: currency rates are single numbers, and single numbers can be multiplied in either order; matrices cannot.

Whiteboard sequence

  1. Draw A and B side by side and write their shapes under them.
  2. Check the inner sizes match and circle them.
  3. Draw the empty answer table of the outer sizes.
  4. Pick a cell, outline its row in A and column in B.
  5. Pair, multiply, add, and write the number in the cell.

Questions learners ask

Why is it not just entry times entry? That would not chain machines. Row-by-column is what makes “B then A” correct.

Is AB always the same as BA? No. Often one does not even exist.

Is a vector a matrix? It can be treated as a matrix with one column, which is why matrix-vector is a special case.

Common misconception

“Matrix multiplication multiplies matching entries.” That is a different operation. Matrix multiplication pairs a row with a column and adds.

Further reading: MML Ch 2.2 (matrix multiplication), including the shape rule and the failure of commutativity.
