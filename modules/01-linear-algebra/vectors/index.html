Vectors: arrows and lists

A vector is a list of numbers in a fixed order. With two or three entries it is also an arrow.

Arrows are drawn in 2D only. A page is flat, so every picture here has two entries. The ideas that carry over unchanged to any number of entries are adding, scaling, dot products and matrix multiplication: each is a rule applied entry by entry, so it does not care how many entries there are. What cannot be drawn is anything with more than three entries (a language model uses hundreds), so treat the arrow as a guide for your intuition and the entry-by-entry rule as the definition.

01 Meaning

Tell a friend where a hidden treasure is: “walk 3 steps east, then 2 steps north”. Two numbers, in a fixed order, describe the whole trip. The list (3, 2) is a vector. Swap the order and you get (2, 3), a different trip.

The same trip is also an arrow. Start at the origin, draw a straight arrow to the point 3 across and 2 up. Two pictures, one object: the list is easy to calculate with, the arrow is easy to see.

Each number in the list is a component (or entry), found by its position. Counting from 1, the vector below has entries v₁, v₂, …, vₙ, and n is its dimension: how many numbers it holds.

v = (v₁, v₂, …, vₙ)

02 Picture

Change the entries, or drag the tip of the arrow. The blue dots show how far across, the teal dots how far up. Then switch to 3 or 5 entries and see what stays and what has to go.

03 Real life

  • Where you are on a map: latitude and longitude, two numbers in a fixed order.
  • Wind: a speed and a direction, which is exactly an arrow.
  • A colour on a screen: how bright its red, green and blue lights are, three numbers in order.
  • One customer's record in a shop's database: (visits per month, items per visit, average spend).

Recognition rule. If a thing needs several numbers in a fixed order to describe it, think “list”. If it also has a size and a direction, think “arrow”.

Spot it. A drone is told to fly 30 m east and then 40 m north. How should its trip be stored so that nothing is lost?

04 Worked example

Predict, then reveal

The small 3 is a position, not a number to multiply by. Count to the third entry from the left.

05 Why and when

One name for a whole list lets you write one rule that works on every entry at once. Without it, a record with 512 numbers would need 512 names.

Use a vector when position carries meaning and the entries belong together. Be careful when the entries use different units, such as an age and an income: the list is still a fine record, but the arrow picture and the idea of “how far apart” then mix unlike things.

What carries over to many dimensions. Everything we do with entries (adding, scaling, taking dot products) works for any dimension. What cannot be drawn: more than three entries. So the arrow is a way to build intuition, not a requirement.

06 How to arrive at it

◆ Convention

Both the list and the arrow are choices of how to write down the same trip. We write the entries in a column or a row, number them from 1, and write bold or with an arrow on top. None of that is forced; another book can do it differently and the maths is unchanged. What is not a choice is that the order of entries must be fixed, or you could not compare two vectors.

07 In an LLM

A language model does not work with words directly. It first turns each token into a vector of numbers, called an embedding. In the original Transformer base model that vector has … entries (Vaswani et al., 2017, §3.4 and Table 3).

Made-up illustration numbers, not real model weights. A token such as “cat” might be stored as a list like …. That is only … entries instead of …, and the numbers are invented to show the shape of the idea.

Simplified. The embedding values are learned during training. Individual entries do not have a neat meaning you can read off, such as “catness”. The useful fact is that the list is a vector, so the rules of this module apply to it.

Explain it back

The list gives the arrow's coordinates and the arrow gives the list a place in space, so they are two views of one thing. Once there are more than three entries there is no room to draw the arrow, but the list and every entry-by-entry rule still work.

Teach it

60-second explanation

“A vector is a list of numbers where the order matters. Say ‘3 east, 2 north’. That is two numbers, and it is also an arrow from where you start. If the list has more numbers we cannot draw it, but we can still add and scale it, because we do it one number at a time. A language model turns every word-piece into a long list like this, hundreds of numbers, so it can do arithmetic on words.”

Everyday analogy

A postal address: street number, street, city, in a fixed order. Where it breaks down: you cannot meaningfully add two addresses, but you can add two vectors.

Whiteboard sequence

  1. Draw two axes and mark the origin.
  2. Write (3, 2) and plot the point.
  3. Draw the arrow from the origin to the point.
  4. Write (2, 3) and draw it too, to show order matters.
  5. Write a 5-entry list and say “no picture, same rules”.

Questions learners ask

Is a vector the arrow or the list? Both are the same object seen two ways. The list is how we compute; the arrow is how we picture.

Does the arrow have to start at the origin? For this module, yes. Moving an arrow without turning it does not change what it means as a displacement, which we use when adding.

What is a 1-entry vector? A single number written as a list. It is the case where the arrow sits on a line.

Common misconception

“A vector is an arrow, so I need a picture.” It is a list first. Most of the vectors in machine learning have too many entries to draw.
