Systems of linear equations

Several equations about the same unknowns, all true at once. They have no solution, exactly one, or infinitely many.

01 Meaning

Two glasses hold 4 litres in total. That alone does not say how much is in each: one equation, two unknowns, a whole line of answers. Now add a second fact: the first glass holds 2 litres more than the second. Two facts, both true at once, are a system of equations, and a solution must satisfy every equation in it.

Back to x + y = 4. The one-row matrix [1 1] times (x, y) is x + y, so x + y = 4 is a system with a single row. The picture on that card was a line of solutions. Adding a second equation adds a second line, and the solutions are the points on both. See Equations in Module 0, and the product [1 1](1, 3) = … from the multiplication card.

Each equation is one row of weights. Stack the rows into a matrix A, the totals into a vector b, and the unknowns into a vector x. The whole system is one statement about the matrix-vector product:

A x = b

There are only three outcomes. The lines can cross at one point (exactly one solution), run side by side and never meet (no solution), or lie on top of each other (infinitely many). A linear system never has exactly two solutions: two lines that share two points are the same line.

Each equation draws a line. The burgundy dot marks the solution when the lines cross once. Try the four buttons, then change the numbers: make the second equation a doubled copy of the first, then nudge one total so they separate.

Two equations, two lines

03 Real life

  • Two shops sell the same two fruits at different prices; two receipts let you find each price.
  • A mixture problem: how much 10% and 30% juice makes a 20% drink?
  • Two moving objects whose paths cross: a time and a place that satisfies both.
  • A balanced budget: income and spending both have to add up.

Recognition rule. If several facts must all hold for the same unknowns, and each fact is a weighted total, it is a linear system. Count the facts and the unknowns, then ask whether the facts are really different.

Spot it. Receipt 1: 2 apples and 1 pear cost 7. Receipt 2: 4 apples and 2 pears cost 14. Can you find the price of one apple?

05 Why and when

Real questions have many facts and many unknowns. Writing them as Ax = b gives one object to reason about, and the tools of the earlier cards apply: if A has an inverse, the answer is x = A⁻¹b.

When it does not fit. If A has no inverse, you cannot use that formula. You then get either no solution or infinitely many, depending on whether the equations contradict each other or repeat each other. The same happens when there are fewer equations than unknowns: one equation in two unknowns, like x + y = 4, leaves a line of answers.

What to reach for instead. Elimination (add multiples of one equation to another, as in the worked example) works for any linear system, with or without an inverse.

06 How to arrive at it

✓ Derived

  1. The requirement. Write “these totals, from these weighted sums of the same unknowns” as one statement.
  2. Obvious candidate. Keep each equation as a separate line of algebra.
  3. Why it falls short. Every equation has the same shape: a row of weights times the unknowns. The matrix-vector product from the Matrices card does exactly “row of weights times the unknowns” for every row at once.
  4. Why Ax = b remains. Stacking the rows is forced: row i of A times x must equal bi. The notation letters A, x and b are a Convention.

Before you continue, predict: why can a linear system never have exactly two solutions?

I have made my prediction: show the reasoning

If x and y both solve Ax = b, then so does every point on the straight line through them: for any number t, A(x + t(y − x)) = Ax + t(Ay − Ax) = b + t(b − b) = b. A straight line has infinitely many points, so having two solutions already means having infinitely many.

07 In an LLM

  • Next-token probabilities are one linear equation. A model’s next-token probabilities p₁, …, pV must add up to 1 (a defining property of a probability distribution). As a system that is one row [1 1 … 1] with total 1. With V = 4 unknowns it leaves … free choices. A real vocabulary has tens of thousands of tokens, so almost all of the probabilities are free, apart from this one equation (and each being at least 0, which this card does not cover).

Simplified. The probabilities also have to be non-negative, which is an inequality, not an equation. The count of free choices above ignores that.

Explain it back

The lines cross at one point (exactly one solution), run parallel without meeting (no solution), or are the same line (infinitely many solutions). There is never a case with exactly two solutions, because two lines that share two points are the same line.

Teach it

60-second explanation

“A system of equations is several facts about the same unknown numbers. Each fact is a row of weights. Stack the rows and you get Ax = b. With two unknowns, each fact is a line. If the lines cross once, you have exactly one answer. If they never meet, none. If they are the same line, infinitely many. Never exactly two.”

Everyday analogy

Two witnesses describing where a stranger stood. Their descriptions cross at one spot, or they conflict, or they say the same thing twice. Where it breaks down: witnesses can be wrong in many ways; lines only cross, miss or coincide.

Whiteboard sequence

  1. Write the two equations one under the other.
  2. Draw both lines on a grid.
  3. Mark where they meet and read off (x, y).
  4. Rewrite as a matrix equation Ax = b.
  5. Draw a second picture where the lines are parallel and one where they coincide.

Questions learners ask

Is elimination the same as using the inverse? Both give the same answer when it is unique. Elimination also works when there is no inverse.

What about three unknowns? Each equation is a flat sheet instead of a line. The same three outcomes still hold.

Why does a repeated equation not help? It says nothing new, so it removes no possibilities.

Common misconception

“Two equations always give a unique answer.” Only if they are genuinely different facts. A repeated or contradictory pair does not.
