Transpose, identity and inverse

Flip a table over its diagonal, find the machine that does nothing, and find the machine that undoes another.

01 Meaning

A table of marks has a row for each student and a column for each test. Turn it on its side and you have a row for each test and a column for each student: same numbers, flipped over the diagonal. That flip is the transpose. Every row becomes a column, so a table with 2 rows and 3 columns becomes one with 3 rows and 2 columns.

Next, a machine that does nothing. Multiplying a number by 1 leaves it unchanged. The matrix version is the identity matrix: 1s down the diagonal and 0s elsewhere. It sends every vector to itself.

Finally, a machine that undoes another. If a matrix A turns v into Av, the inverse A⁻¹ turns Av back into v. Not every machine can be undone. The inverse exists only for a square matrix (as many rows as columns) whose determinant is not zero. For a 2×2 matrix with rows (a, b) and (c, d), the determinant is ad − bc; on this card we use it only as that test.

(Aᵀ)ᵢⱼ = Aⱼᵢ, A A⁻¹ = I

03 Real life

  • A timetable read by day instead of by subject: the same table, flipped.
  • Pressing “undo” after one edit: the inverse of that edit.
  • Converting euros to dollars and back, when the rate is known: each conversion undoes the other.
  • Putting on socks then shoes. To undo, the shoes come off first: reverse the order.

Recognition rule. If you swap rows for columns, think “transpose”. If a step must be exactly reversible, ask for its inverse, and expect the order of a chain to reverse.

Spot it. You blur a photo with a strong filter that turns many different pixel patterns into the same result. Can a single matrix “un-blur” it exactly?

04 Worked example

Predict, then reveal

Entry (3, 1) of Aᵀ is entry (1, 3) of A: swap the two positions.

05 Why and when

The transpose lets you pair rows with rows when a formula wants a row against a row. The identity is the starting point of every “undo”: an inverse is defined as the matrix that brings you back to the identity. The inverse lets you reverse a step exactly.

When it does not fit. An inverse exists only for a square matrix with a nonzero determinant. A tall or wide matrix, or a square one that squashes different inputs together, has none. Do not write A⁻¹ as “1/A”: it is a matrix, not a reciprocal of every entry.

Order. Reversing a chain reverses the order: (AB)ᵀ = BᵀAᵀ and (AB)⁻¹ = B⁻¹A⁻¹. The tempting AᵀBᵀ and A⁻¹B⁻¹ are wrong in general; the worked example shows a case where they differ.

06 How to arrive at it

✓ Derived

  1. The requirement. A machine B that undoes A must satisfy B(Av) = v for every v. So BA must act like multiplying by 1: it must be the identity.
  2. The identity is forced. The only matrix with Iv = v for every v has 1s on the diagonal and 0s elsewhere. Its columns are the unit arrows, which must land on themselves.
  3. The order is forced. To undo “A then B” (the product BA when vectors are columns), undo B’s step last-first: apply B⁻¹ before A⁻¹. That is (BA)⁻¹ = A⁻¹B⁻¹, and the same reasoning gives (AB)⁻¹ = B⁻¹A⁻¹.
  4. When it fails. If A sends two inputs to one output, no B can recover which one it was. The 2×2 test for that is ad − bc = 0.

The name and symbol “ᵀ” for the transpose are a Convention; the swap itself is simply what “rows become columns” means.

Before you continue, predict: is (AB)⁻¹ equal to A⁻¹B⁻¹ for the A and B in the worked example?

I have made my prediction: show the reasoning

No. For those matrices AB ≠ BA, and the last two steps of the worked example show the entries: B⁻¹A⁻¹ matches the inverse of AB, while A⁻¹B⁻¹ gives a different matrix.

07 In an LLM

  • Transpose in attention. In the original Transformer, the attention scores are computed from QKᵀ, the queries times the transpose of the keys (Vaswani et al., 2017, §3.2.1). For 4 tokens with key size … (illustrative: the paper's sizes, but 4 tokens), Q is 4×…, Kᵀ is …×4, and the product is …: one score for every pair of tokens, using … multiplications.
  • No inverse for a narrowing projection. The query projection in that paper maps a …-entry vector to a …-entry one, so its matrix is …, which is not square. A matrix that is not square has no inverse, so that step cannot be undone exactly. This follows from the shapes alone; it says nothing about what any trained model learns.

Simplified. The paper stores one row per token, so its matrices are the transposes of the column-convention ones used on this site. Real models also have many heads and a scaling factor in the scores; this card keeps only the shape of the step.

Teach it

Everyday analogy

The transpose is turning a page of a table on its side. The inverse is the “undo” button, which only works if no information was lost. Where it breaks down: “undo” in an app remembers history; a matrix inverse uses only the output.

Common misconception

“A⁻¹ is 1 divided by A, entry by entry.” It is a different matrix, defined by A A⁻¹ = I, and for some matrices it does not exist.
